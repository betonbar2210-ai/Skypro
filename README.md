# Проект - "Я студент Skypro"
Я студент - виджет, который показывает несколько последних успешных банковских операций клиента

## Установка:
1. Клонируйте репозиторий:  
```https://github.com/betonbar2210-ai/MyProject.git```

## Основные функции:
1. Обработка данных клиента по номеру счета или номеру карты и вывод на экран данных в замаскированном виде
* Пример работы:
  - Ввод номера карты:  
       7000792289606361      #входной аргумент  
       7000 79** **** 6361   #выход функции
  - Ввод Счета:  
       73654108430135874305   #входной аргумент  
       **4305   #выход функции
  
2. Обработка операций и вывод успешных операций по ключу "state" = "EXECUTED"
* Пример работы:
  - Входные данные:  
    {"id": 41428829, "state": "EXECUTED", "date": "2019-07-03T18:35:29.512364"},    
    {"id": 594226727, "state": "CANCELED", "date": "2018-09-12T21:27:25.241689"}
  - Вывод:  
    {"id": 41428829, "state": "EXECUTED", "date": "2019-07-03T18:35:29.512364"}


3. Обработка операций и сортировка по убыванию дат:
* Пример работы:
  - Входные данные:  
    {"id": 41428829, "state": "EXECUTED", "date": "2019-07-03T18:35:29.512364"},  
    {"id": 939719570, "state": "EXECUTED", "date": "2018-06-30T02:08:58.425572"},   
    {"id": 594226727, "state": "CANCELED", "date": "2018-09-12T21:27:25.241689"},  
    {"id": 615064591, "state": "CANCELED", "date": "2018-10-14T08:21:33.419441"}
  - Вывод:  
    {"id": 41428829, "state": "EXECUTED", "date": "2019-07-03T18:35:29.512364"},  
    {"id": 615064591, "state": "CANCELED", "date": "2018-10-14T08:21:33.419441"},  
    {"id": 594226727, "state": "CANCELED", "date": "2018-09-12T21:27:25.241689"},  
    {"id": 939719570, "state": "EXECUTED", "date": "2018-06-30T02:08:58.425572"}
  

4. Модуль generators.py:  
4.1 Функция возврата итератора, который поочередно выдает транзакции, по ключу валюты (например, USD)  
4.2 Функция-генератора возвращает описание каждой операции по очереди  
4.3 Функция-генератор, поочередно выдает номера банковских карт в формате XXXX XXXX XXXX XXXX,
    в заданном диапазоне от 0000 0000 0000 0001 до 9999 9999 9999 9999:
  - Пример:  
    ввод: от 1234 до 1235  
    вывод:  
     0000 0000 0000 1234  
      0000 0000 0000 1235
